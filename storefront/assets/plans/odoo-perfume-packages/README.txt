ODOO PERFUME — PACKAGE IMAGE SET

This folder contains three separate premium package visuals:
1. Diamond Package
2. Golden Package
3. Silver Package

Images are exported as 2048 x 2048 PNG files. The visuals were generated as a single three-panel artwork, then divided into separate panels and upscaled with high-quality Lanczos resampling. The individual exports are therefore suitable for website mockups and marketing drafts, but are not native, independently generated 2048px renders.
