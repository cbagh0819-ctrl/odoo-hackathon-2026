ODOO PERFUME — CINEMATIC LUXURY STOREFRONT

RUN LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.
   For a local web server, run this command from the extracted folder:
       python -m http.server 8000
   Then visit:
       http://localhost:8000

WHAT IS INCLUDED
- Responsive luxury storefront based on the supplied Odoo Perfume design.
- Cinematic hero artwork using the Odoo Perfume campaign image.
- Navigation for Home, Shop, Collections, and Our Story.
- Men, Women, Unisex, and Premium collection links.
- Product filtering and live search.
- Wishlist interactions saved in browser localStorage.
- Shopping bag with quantity controls, subtotal, and saved cart state.
- Newsletter demo form and responsive mobile navigation.
- Generated visual assets included locally in /assets.

DEMO CONTENT
Product names, descriptions, and INR prices are sample storefront content. The product photos
are visual mockups. Confirm product details, pricing, inventory, delivery, returns, and legal
copy before publishing a live store.

BACKEND / CHECKOUT LIMITATIONS
This is a front-end prototype. It does not connect to a live inventory database, customer
accounts, order-management system, email service, shipping provider, or payment gateway.
The checkout button displays a demo message. Connect a backend and a payment provider such
as Razorpay or Stripe before accepting customer payments.
