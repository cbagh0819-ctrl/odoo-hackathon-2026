# Frontend Application — Odoo Perfumes Portal
**Lead**: Abhisek Nayak (`abhisek1567` — Frontend & UI/UX Specialist)

## Architecture Overview
This directory contains the user interface built with React 18, Vite, and Tailwind CSS:
- `src/pages/FinanceDashboard.jsx`: Cinematic dark luxury dashboard with live metrics, SVG sparks, and interactive Bézier revenue charts.
- `src/pages/LiveStoreView.jsx`: Customer fragrance discovery and instant subscription storefront.
- `src/pages/BillingDayView.jsx`: Operational view for executing recurring billing days and managing invoices.
- `src/components/Sidebar.jsx`: Vertical navigation with instant persona switching.
- `src/api.js`: Unified API client managing JWT authentication and request execution.

## Running the Application
```bash
npm install
npm run dev
```
Development server operates at `http://localhost:3000`.
